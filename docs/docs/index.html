Workflow

Dari brief sampai siap tayang.

Alurnya dibuat singkat dan jelas supaya kamu tahu apa yang terjadi di setiap tahap.

  1. Brief

    Kamu ceritakan tujuan, target audiens, dan referensi.

  2. Skrip atau konsep

    Saya tulis draf, kamu beri masukan.

  3. Produksi dan edit

    Video dibuat dan diedit sesuai skrip yang disetujui.

  4. Revisi dan serah

    Perbaikan akhir, lalu file dikirim siap pakai.
